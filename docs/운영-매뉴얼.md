# M-SPACE 운영 매뉴얼 (학과실 조교·근로학생용)

- 문서 버전: v0.1 (2026-10-21)
- 화면: 휴대폰·PC 브라우저에서 접속 → 아래 메뉴 **관리** (관리자 계정만 보여요)

## 1. 바뀌는 것과 그대로인 것

| 지금 (종이) | 시범운영 (시스템) |
|---|---|
| 학생이 학과실에 와서 대여 서류 작성 | 학생이 휴대폰으로 방·시간을 골라 예약 (즉시 확정) |
| 학번·이름·전화번호를 매번 기입 | 가입 때 한 번만 등록 → 관리자 화면에 자동 표시 |
| 학생증 제출 | **그대로**: 실물 학생증을 보고 학번·이름 확인 → 화면에서 체크 (사진은 받지 않아요) |
| 키 건네기 | **그대로**: 키를 건네고 **키 지급** 버튼 |
| 키 돌려받기 | **그대로**: 키를 받고 **반납 확인** 버튼 (종료 시각이 지났으면 자동으로 지연 반납 기록) |
| 노쇼 확인·기록 | 시작 15분이 지나도록 키를 안 받으면 시스템이 자동으로 노쇼 처리, 2주 안에 2번이면 7일 예약 제한 |
| 대장 정리 | 예약·키 기록이 자동으로 남아요 (누가, 언제, 어느 관리자가 처리했는지) |

시범운영 기간에는 **종이 대장도 함께 둬요.** 시스템이 멈추면 바로 종이로 돌아가요(5장).

## 2. 하루 업무

### 오늘 화면 (관리 → 예약·키)
위에 오늘 **예약 / 이용 중 / 반납 지연 / 노쇼** 수가 나오고, 아래에 오늘 예약이 시작 시각 순으로 나와요. 30초마다 저절로 새로고침돼요.

### 키 지급
1. 학생이 오면 실물 학생증을 받아요.
2. 해당 예약 카드의 **키 지급**을 눌러요.
3. 화면에 나온 학번·이름이 학생증과 같은지 보고 체크해요. **다르면 지급하지 않아요**(남의 학번으로 가입했을 수 있어요 → 3장 비활성화).
4. **본인 확인 완료 · 키 지급** → 키와 학생증을 건네요. 예약이 "이용 중"으로 바뀌어요.

- 키는 **시작 10분 전부터 시작 15분 후까지** 줄 수 있어요. 그 밖의 시간에 누르면 안내 문구가 나와요.
- 15분이 지나면 노쇼로 바뀌어서 키를 줄 수 없어요. 사정이 있으면 학생이 새로 예약하거나, 빈 시간이면 현장에서 처리해요.

### 반납 확인
키를 받으면 그 예약의 **반납 확인**을 눌러요. 종료 시각이 지났으면 "반납 지연"으로 기록되고, 일찍 반납하면 남은 시간은 다른 학생이 예약할 수 있게 열려요.
종료 시각이 지났는데 반납하지 않은 예약은 카드 테두리가 빨갛고, 위의 **반납 지연** 수에 잡혀요 → 학생에게 연락해요(관리자 화면에서는 전화번호 전체가 보여요).

### 예약 취소 (관리자)
점검·행사 등으로 방을 못 쓰게 되면 해당 예약의 **예약 취소** → 사유 입력 → **취소하기**. 학생의 내 예약 화면에 사유가 보여요. 키를 이미 준 예약(이용 중)은 취소할 수 없고 반납 확인으로 끝내요.

## 3. 회원 관리 (관리 → 회원)

| 상황 | 할 일 |
|---|---|
| 비밀번호를 잊었어요 | 학생증으로 본인 확인 → **비밀번호 초기화** → 사유 입력 → 화면의 임시 비밀번호를 학생에게 직접 알려 줘요(이 화면에서만 보여요). 학생은 다음 로그인 때 비밀번호를 바꾸게 돼요 |
| 남이 내 학번으로 가입했어요 | 학생증으로 본인 확인 → 그 계정 **비활성화** → 본인이 다시 가입해요. 비활성화하면 키 받기 전 예약은 자동으로 취소돼요 |
| 탈퇴(개인정보 삭제)를 원해요 | 계정 **비활성화** 후 서버 담당자에게 알려 파기 절차를 실행해요 (`docs/배포-가이드.md` 7장) |

모든 조치(초기화·비활성화·취소·제한 해제)는 처리한 관리자와 사유가 기록으로 남아요.

## 4. 노쇼와 이용 제한 (관리 → 이용 제한)

- 시작 15분이 지나도록 키를 안 받으면(시험기간 개방 때는 체크인을 안 하면) 자동으로 노쇼예요.
- 2주 안에 노쇼 2번이면 7일 동안 예약할 수 없어요. 학생이 예약하려 하면 언제까지 제한인지 안내돼요.
- 아프거나 시스템 장애처럼 사정이 확인되면 **이용 제한** 탭에서 **제한 해제** → 사유 입력. 해제한 뒤에는 이전 노쇼를 다시 세지 않아요.

## 5. 시스템이 안 될 때

1. 종이 대장으로 바로 바꿔서 평소처럼 대여해요.
2. 서버 담당자에게 알려요 (연락처는 시범운영 시작 때 학과실에 공유).
3. 복구된 뒤 그 사이 노쇼로 잘못 처리된 학생이 있으면 이용 제한에서 해제해요.

## 6. 시험기간 개방 (예정 기능 안내)

시험기간처럼 방을 종일 열어두는 기간에는 키 대신 학생이 앱에서 **이용 시작·이용 종료**를 눌러요. 이 기간 등록은 지금은 서버 담당자가 DB에 넣고(관리 화면은 2차), 등록되면 현황판 위에 기간 이름이 보여요.
