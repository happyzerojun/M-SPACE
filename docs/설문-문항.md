# M-SPACE 예약 시스템 학생 설문 (구글폼 문항 초안)

- 대상: IT융합대학 학생 (M-SPACE실 이용자·예비 이용자)
- 목적: ① 데모 화면이 쓰기 쉬운지 확인 ② 아직 확정하지 않은 운영 규칙에 학생 의견 반영 (요구사항 7장 결정 항목)
- 예상 소요: 5분 내외 · 문항 16개 (필수 12, 선택 4)
- **개인정보는 받지 않아요.** 학번·이름·전화번호 문항이 없고, 구글폼 설정에서 "이메일 주소 수집"을 꺼 주세요.
- 진행 순서: 데모를 먼저 써 보고(과제 3개) → 설문에 답해요

> **자동 생성:** `scripts/create-survey-form.gs`를 https://script.google.com 새 프로젝트에 붙여 넣고 `createSurveyForm`을 실행하면, 아래 문항 그대로 폼과 응답 시트가 내 드라이브에 만들어져요(이메일 수집 꺼짐). 실행 로그에 응답 주소가 나와요.
>
> 손으로 만들 때: 섹션 4개로 나누고, 1~5점 척도는 "선형 배율", 객관식은 "객관식 질문", 여러 개 고르기는 "체크박스"로 만들면 돼요. 데모 주소는 폼 설명란 맨 위에 넣어 주세요.

## 폼 제목·설명 (그대로 붙여 넣기)

**제목:** M-SPACE실 온라인 예약 시스템 의견 조사

**설명:**
> M-SPACE실 예약과 키 대여를 웹으로 옮기려고 해요. 아래 데모를 휴대폰으로 3분만 써 보고 답해 주세요.
> 데모 주소: https://m-space-rho.vercel.app
> 데모는 가짜 데이터로 동작하고, 입력한 내용은 내 브라우저에만 저장돼요. 회원가입은 하지 않아도 되고, 해 본다면 실제 학번·전화번호 대신 아무 숫자나 넣어 주세요.
> 이 설문은 학번·이름 등 개인정보를 받지 않아요.
>
> **데모에서 해 볼 것 3가지**
> 1. 첫 화면에서 오늘·내일 방이 비어 있는지 보기
> 2. 빈 시간을 눌러 "데모 학생으로 바로 시작하기"로 예약하기 → "내 예약"에서 취소해 보기 (회원가입 없이 돼요)
> 3. 날짜를 모레 이후로 바꿔 "시험기간"이라고 나오는 날에 예약해 보기 (시험기간은 키 없이 앱에서 "이용 시작"을 눌러요)
